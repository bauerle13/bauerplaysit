# bauerplaysit.com

Cities: Skylines II channel site. Static GitHub Pages site; a GitHub Action refreshes videos, series and mods every 6 hours.

## One-time setup

### 1. Create the repo
1. Create a new GitHub repo (for example `bauerplaysit`) and push these files to `main`.
2. Repo **Settings → Pages**: Source = *Deploy from a branch*, Branch = `main` / root.
3. Repo **Settings → Actions → General → Workflow permissions**: choose **Read and write permissions** so the sync can commit.

### 2. Point the domain
At your domain registrar, add DNS records for `bauerplaysit.com`:

| Type  | Name | Value |
|-------|------|-------|
| A     | @    | 185.199.108.153 |
| A     | @    | 185.199.109.153 |
| A     | @    | 185.199.110.153 |
| A     | @    | 185.199.111.153 |
| CNAME | www  | `<your-github-username>.github.io` |

Then in **Settings → Pages**, confirm the custom domain shows `bauerplaysit.com` (the `CNAME` file sets it) and tick **Enforce HTTPS** once it's available.

### 3. Create the Google Sheet
Make a sheet with two tabs named exactly **Series** and **Mods**. Column headers are in `sheet-template/`.

**Series** (one row per city build):

| Series | Playlist URL | Status | Description | Playset |
|---|---|---|---|---|
| Maple Harbor | https://www.youtube.com/playlist?list=PL… | Active | A coastal city… | *(leave blank for now)* |

- **Status**: `Active` shows on the home page; `Complete` only shows on the Series page.
- Episodes for each series come straight from its YouTube playlist.

**Mods** (one row per mod per series):

| Series | Mod URL | Note |
|---|---|---|
| Maple Harbor | https://mods.paradoxplaza.com/mods/74604/Windows | Optional note on the card |

The mod's name, author and details are pulled from Paradox Mods automatically. A bare mod ID (`74604`) also works.

Share the sheet: **Share → General access → Anyone with the link → Viewer**. Copy the ID from its URL (`docs.google.com/spreadsheets/d/<THIS PART>/edit`).

### 4. Connect the sheet
Repo **Settings → Secrets and variables → Actions → Variables** tab → **New repository variable**:
- `SHEET_ID` = the sheet ID
- `PATREON_URL` = your Patreon page, once it exists (the Support page switches from "Coming soon" automatically)

### 5. Run the first sync
**Actions → Sync videos, series and mods → Run workflow**. After that it runs every 6 hours on its own. The log shows a count of videos, series and mods, plus any warnings.

## What updates automatically
- Latest uploads (Shorts are filtered out) from the @BauerPlaysIt channel
- Each series' episodes from its playlist
- Mod names/authors/details from Paradox Mods
- Discord member and online counts

If any source is down, the site keeps the last good data instead of going blank.

## Files
- `index.html`, `series.html`, `mods.html`, `community.html`, `support.html`: pages
- `_includes/`: shared head, header and footer
- `assets/`: CSS, JS, logo
- `data/site-data.json`: generated by the sync; don't hand-edit
- `scripts/sync.mjs`: the sync job
- `config/site.json`: YouTube handle, Discord invite and sheet tab names
